# Changelog

Todas las modificaciones importantes de este proyecto se documentarán en este archivo.

## [0.1.0] - 2025-07-07

### Añadido
- Primera implementación
- Gestión de transacciones: crear, editar y eliminar
- Almacenamiento local con `AsyncStorage`
- Muestra de transacciones (formato lista / diaria / semanal / mensual)
- Exportación e importación básica de datos en Excel

---

## [0.2.0] - 2025-07-20

### Añadido
- Validación de categorías al crear una transacción: ahora solo se puede seleccionar una categoría válida según el tipo (ingreso o gasto).
- Nueva pantalla de ajustes accesible desde el menú de navegación.
- Botón flotante para añadir transacciones desde la vista principal.
